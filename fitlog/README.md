# FitLog — Workout Library

A dark, no-nonsense gym companion. Pick a lift, lock it into today's plan, and watch the week's work add up.

Live:_add your link_  |  **Repo:** _add your link_

## Technologies
- Next.js 14 (App Router)
- Tailwind CSS
- lucide-react (icons)
- react-hot-toast (notifications)

##  Features
1. Responsive 12-workout library grid loaded from an API (with a loading animation).
2. Workout details page with specs table and step-by-step instructions.
3. "Add to today's plan" / "Save for later" with toast messages and live navbar badges.
4. My Plan page with live Exercises / Minutes / Calories stats and Today's Plan / Saved tabs.
5. Sort by Duration, Calories or Rating; Mark as Done and Remove actions.
6. Data saved in localStorage; plan capped at 5 lifts; custom 404 page.

## Run locally
```bash
npm install
npm run dev
```
